Desativar disco

O Windows para de usar o disco: a letra some e nenhum programa acessa os arquivos. Nada é apagado — ao ativar de novo, tudo volta como estava. Ele continua desativado mesmo depois de reiniciar o PC, até você ativá-lo aqui. O Windows vai pedir confirmação de administrador.
